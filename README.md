# Dr Mario
Dr. Mario is a tetris like game where you drop pills down and attempt to clear the viruses.

# How to play the game:

The easiest way to play the game is to download drmario.asm and put the code into this website: https://1whatleytay.github.io/saturn. Press play and go to the bitmap. Press on the bitmap. The game will prompt you to choose a level and then start the game. Use WASD to controll the pill.
