# Dr Mario
Dr. Mario is a tetris like game where you drop pills down and attempt to clear the viruses.

# How to play the game:

The easiest way to play the game is to download drmario.asm and put the code into this website: https://1whatleytay.github.io/saturn. Press play and go to the bitmap. Make sure the bitmap display width and height are set to 256 with the units being set to 4. Press on the bitmap. The game will prompt you to choose a level and then start the game. Use WASD to controll the pill (W rotates the pill). Press Q to quit. Press P to pause.
